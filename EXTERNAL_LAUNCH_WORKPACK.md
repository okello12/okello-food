# Okello Food external launch workpack

Status: working governance pack after v47. This file separates evidence that can be prepared internally from decisions that require founder facts, a qualified reviewer, a regulator/self-assessment outcome or a rights-holder response.

## Why this exists

The engineering remediation is no longer the main launch constraint. The remaining launch gates cannot be closed by another JavaScript commit. They need attributable external evidence.

| Workstream | Internal preparation | External evidence needed | Target gate |
| --- | --- | --- | --- |
| ICO fee | `ICO_FEE_ASSESSMENT_INPUTS.md` | Completed ICO fee self-assessment for the actual operating entity/trading status | Before broad public beta |
| DPIA / controller / Article 9 | `PRIVACY_DPIA_DRAFT.md` | Founder decisions plus qualified privacy review where possible | Before broad public beta |
| Operator identity / contact | privacy pages already have a placeholder | Final legal/trading identity and monitored privacy contact | Before broad public beta |
| FAO/WAFCT rights | `FAO_WAFCT_PERMISSION_REQUEST.md` | Written FAO permission with commercial terms, or formal decision not to use WAFCT production values | Before any WAFCT production extraction |
| Food-composition sign-off | `NUTRITION_REVIEWER_BRIEF.md`, source register and evidence queue | Registered dietitian / food-composition reviewer sign-off on priority tranche | Before authoritative nutrition claims |
| Laboratory gaps | `LAB_ANALYSIS_RFP_TEMPLATE.md` | Quotes, agreed recipe/sample protocol and commercial data-rights terms | Only after licensed-source gap analysis |
| Real adoption | `BETA_90_DAY_PROTOCOL.md` and `BETA_RECRUITMENT_PACK.md` | 30–50-user observed/returned evidence across multiple food backgrounds | Product continuation / investment gate |

## Current regulator/source references checked 8 September 2026

- ICO data protection fee self-assessment: https://ico.org.uk/fee-checker
- ICO fee exemptions: https://ico.org.uk/for-organisations/data-protection-fee/data-protection-fee/exemptions/
- ICO DPIA guidance: https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/accountability-and-governance/data-protection-impact-assessments-dpias/
- ICO special category guidance: https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/lawful-basis/special-category-data/
- ICO final 2026 storage/access guidance: https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guidance-on-the-use-of-storage-and-access-technologies/
- ICO Children's Code service-scope guidance: https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/childrens-information/childrens-code-guidance-and-resources/age-appropriate-design-a-code-of-practice-for-online-services/services-covered-by-this-code/
- FAO rights and permissions: https://www.fao.org/publications/about-fao-publishing/permissions/

The ICO notes that some DPIA guidance is under review following Data (Use and Access) Act changes. The project must re-check the regulator's live guidance when the assessment is signed off rather than treating this repository copy as immutable legal advice.

## Closure rule

A workstream closes only when its named external evidence is attached or recorded. A draft, checklist, code change or founder intention is not external evidence.
